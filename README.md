# career-guides-bot
Telegram бот для продажи карьерных гайдов

## Контент-завод для Instagram

В `content-factory/` и `.claude/agents/` живут 8 ИИ-агентов, которые ведут
продвижение гайдов в Instagram (@careers.guides): Аналитик, Контент-менеджер,
Копирайтер, Карусель-мейкер, Рилс-мейкер, Дизайнер, Ревизор, Личный ассистент.
Как это работает и как запускать — см. `content-factory/README.md`.
