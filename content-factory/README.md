# Контент-завод для @careers.guides

8 ИИ-агентов (Claude Code субагентов), которые вместе ведут продвижение гайдов
в Instagram. Определения агентов лежат в `.claude/agents/*.md` — это часть
репозитория, поэтому они доступны в любой сессии Claude Code, открытой на этом
проекте.

## Агенты и порядок работы

```
1. Аналитик          — статистика + горячие новости
        ↓
2. Контент-менеджер   — контент-план
        ↓
3. Копирайтер         — тексты постов/каруселей/рилсов/сторис
        ↓            ↘            ↘
4. Карусель-мейкер  5. Рилс-мейкер  6. Дизайнер   (параллельно, каждый по своей части)
        ↓            ↙            ↙
7. Ревизор            — финальная проверка всего
        ↓
   (публикация/постановка в очередь Metricool — руками или по твоей команде)

8. Личный ассистент — работает не в цепочке, а сбоку: задачи, напоминания,
   организационные мелочи на всех этапах.
```

## Как запускать

**Кодовое слово: «ВЗЛЁТ».** Напиши его Claude Code в любой сессии на этом
репозитории — это значит "прогони весь конвейер целиком": Claude сам вызовет
всех агентов по очереди (Аналитик → Контент-менеджер → Копирайтер →
Карусель-мейкер/Рилс-мейкер/Дизайнер → Ревизор), передавая файлы между ними.
Запуск только ручной, по этому слову — автозапуска по расписанию нет и не
планируется, если явно не попросишь иначе.

Можно и по отдельности, если нужен конкретный агент, а не весь конвейер:
- «Запусти Аналитика за последнюю неделю»
- «Пусть Контент-менеджер составит план на две недели по свежему отчёту»
- «Копирайтер, напиши посты по текущему плану»

Каждый агент читает и пишет файлы в этой папке — так следующий агент в цепочке
видит, что сделал предыдущий, и весь прогресс остаётся в git (можно посмотреть
историю, откатить, дать фидбек прямо в файле).

**Уведомления.** Пока сессия открыта — результат каждого агента (включая
финальный вердикт Ревизора) приходит новым сообщением прямо в чат. Если
владелец отошёл, Claude может отдельно отправить push/desktop-уведомление о
готовом результате (на телефон — если подключён Remote Control к аккаунту).

## Структура папки

- `brand-context.md` — источник правды: продукты, аудитория, аккаунт, воронка,
  периодичность публикаций, визуальный стиль. Правь здесь, если что-то в
  бизнесе поменялось.
- `voice-guide.md` — голос бренда, подтверждён владельцем аккаунта на реальном
  примере поста.
- `topics-log.md` — лог всех тем/углов подачи, которые уже использовались —
  Контент-менеджер не повторяется.
- `competitors.md` — конкуренты/источники вдохновения в нише, которые
  анализирует Аналитик.
- `insights-log.md` — накопленные закономерности (что реально подтвердилось на
  практике за несколько наблюдений), отдельно от разовых находок отчёта.
- `photos/` — реальные фото владельца аккаунта для Дизайнера/Карусель-мейкера/
  Рилс-мейкера.
- `reports/` — отчёты Аналитика.
- `plans/` — контент-планы от Контент-менеджера.
- `drafts/` — черновики текстов от Копирайтера.
- `carousels/` — карусели от Карусель-мейкера.
- `reels/` — рилсы от Рилс-мейкера.
- `design-briefs/` — визуалы от Дизайнера.
- `qa/` — ревью от Ревизора.
- `tasks/todo.md` — открытые дела от Личного ассистента.

## Публикация

Постановка в очередь Metricool (`createScheduledPost`) — сознательно не отдана
ни одному агенту автоматически: Ревизор доводит контент до вердикта "готово",
а публикацию ты подтверждаешь явно (попроси Claude поставить конкретный
готовый пост в очередь на конкретное время). Так ничего не уйдёт в паблик без
твоего "ок".
