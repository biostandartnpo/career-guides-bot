# Твои фото для агентов

Клади сюда реальные фотографии (свои, рабочего места, продукта и т.п.), которые
агенты могут использовать в контенте — как есть или как референс для ИИ-генерации.

**Важно:** репозиторий публичный. Всё, что попадёт в эту папку через коммит,
станет доступно всем в интернете (и останется в истории git, даже если потом
удалить файл). Клади сюда только то, что не страшно светить публично.

## Как называть файлы

Коротко и по смыслу, чтобы агенты (и ты сам) сразу понимали, что на фото, без
необходимости открывать каждый файл:

```
2026-07-portret-rabochee-mesto.jpg
2026-07-obложка-avtopost-demo.png
```

## Как агенты используют фото из этой папки

1. **Дизайнер, Карусель-мейкер, Рилс-мейкер** перед генерацией с нуля сначала
   смотрят сюда — если есть подходящее реальное фото, используют его вместо
   полностью ИИ-сгенерированной картинки (или наравне с ней).
2. Фото может пойти в пост/карусель **как есть** (без обработки) — тогда агент
   просто укажет путь к файлу в своём результате, и его нужно будет прикрепить
   при публикации.
3. Фото может стать **референсом для ИИ-генерации** (Soyuz) — агент загружает
   его напрямую из репозитория (никуда вовне публиковать не нужно, механизм
   работает с локальными файлами) и получает на его основе новое изображение
   в похожем стиле/сюжете.
4. Фото может пойти **в Canva** как элемент дизайна (текст поверх фото и т.п.) —
   для этого Canva нужна публичная ссылка на файл; поскольку репозиторий
   публичный, такая ссылка у любого закоммиченного файла уже есть в виде
   `https://raw.githubusercontent.com/biostandartnpo/career-guides-bot/<ветка>/content-factory/photos/<имя-файла>`.
   **Важно для агентов:** используй ссылку на файл в ветке `main` (после того,
   как фото туда смержено), а не на текущую рабочую ветку — рабочие ветки после
   мержа обычно удаляются, и ссылка перестанет работать.

## Как загрузить фото

Так же, как и другие файлы в этом репозитории: на GitHub, на нужной ветке,
«Add file» → «Upload files» → перетащи фото в эту папку (`content-factory/photos/`,
не начинается с точки, так что drag&drop работает без сложностей) → Commit changes.
