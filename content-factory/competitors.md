# Конкуренты и источники вдохновения в нише

Список аккаунтов, за которыми Аналитик регулярно следит при поиске трендового
контента и "фишек". Пополняется самим Аналитиком при каждом прогоне (новые
находки дописываются сюда), можно и нужно дополнять вручную.

Если какой-то из этих аккаунтов уже добавлен как отслеживаемый конкурент в
Metricool — Аналитик может получить по нему количественную статистику
(`getAnalyticsDataByMetrics` с коннектором `competitor posts`/`competitor reels`,
network `instagram`). Если не добавлен — Аналитик ищет по нему через
WebSearch/WebFetch (публичные данные, без точных цифр вовлечённости).

|---|---|---|---|
