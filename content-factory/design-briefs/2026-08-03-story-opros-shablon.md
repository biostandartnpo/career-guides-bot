# Визуал — Шаблон сторис-опроса (переиспользуемая рубрика)

Для: сторис 03.08 "Что разобрать в следующем посте?" и сторис 09.08 "Какая
тема этой недели зашла больше всего?" — один и тот же переиспользуемый шаблон
для обеих публикаций (и для будущих выпусков опросов).
Источник: `content-factory/drafts/2026-08-03-story-opros-tema.md`,
`content-factory/drafts/2026-08-09-story-opros-itogi-nedeli.md`,
`content-factory/plans/2026-07-28-plan.md` (примечание: единый фирменный
стиль для сторис-опросов, чтобы сторис не выглядели "самодельными").
Инструмент: Canva (`generate-design`, design_type `your_story`, 9:16)
Результат: НЕ СГЕНЕРИРОВАНО — см. "Статус"

## Промпт/бриф, который использовал

Шаблон вертикальной Instagram-сторис (9:16) для регулярной рубрики
опрос-стикера аккаунта careers.guides (карьерные гайды для будущих
бортпроводников) — визуальный «брат» шаблона квиза «Тест дня», но узнаваемо
отличается на первый взгляд (добавлен холодный тиловый акцент рядом с
коралловым). Тёплый дружелюбный флэт-иллюстративный фон, НЕ фотореалистичный,
без корпоративного ИИ-глянца. Мягкие авиационные мотивы: облака, самолёт,
оставляющий мягкий раздваивающийся след (символ выбора между вариантами).
Палитра: коралл/оранжевый + мягкий тил + кремовый.

Текст-бейдж сверху: «Опрос». Заголовок: «Что разобрать в следующем посте?».
ВАЖНО: в середине и нижней части кадра должно остаться большое пустое
незагруженное пространство без декоративных элементов и текста — туда потом
вручную добавляется нативный стикер-опрос/квиз Instagram при публикации. Это
переиспользуемый шаблон рубрики — в будущих выпусках (включая еженедельный
опрос по итогам недели 09.08, заголовок там будет «Какая тема этой недели
зашла больше всего?») будет меняться только заголовок-вопрос.

Примечание (техническое, из брифа Копирайтера): стандартный опрос-стикер
Instagram поддерживает только 2 варианта ответа, а в обоих черновиках по 3
варианта — Копирайтер рекомендует использовать квиз-стикер (до 4 вариантов)
вместо обычного опроса. На визуал шаблона это не влияет (пустая зона под
любой стикер одинаковая), но при финальной сборке сторис нужно выбрать
правильный тип стикера.
